
# World Map Game

A simple game-like interface for managing a world map.

Uses:

* Html5 Canvas

### Layers

#### Background

Places a background image on the canvas.

#### Grid

Places a grid on the canvas.

#### Underground

Places underground tiles on the canvas.

#### Ground

Places ground tiles on the canvas.

#### Labels

Places label objects on the canvas.

#### Object

Places objects on the canvas.
